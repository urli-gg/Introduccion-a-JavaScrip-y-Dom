# JavaScript: Características y Tipos de Datos

JavaScript es un lenguaje de programación interpretado, dinámico y orientado a objetos, que se usa principalmente para crear páginas web interactivas

### Caracteristicas principales
- **Interpretado:** se ejecuta directamente en el navegador.

- **Multiparadigma:** permite programación orientada a objetos, funcional y procedimental.

- **Basado en eventos:** responde a acciones del usuario como clics o teclas.

- **Tipado dinámico y débil:** no es necesario declarar tipos de variables, y permite operaciones entre diferentes tipos.

- **Asincronía:** puede manejar tareas en paralelo con callbacks, promesas o async/await.

- **Compatible con múltiples plataformas:** funciona en navegadores modernos y en servidores con Node.js.

### Tipos de Datos

**Primitivos (inmutables):**

- string → texto

- number → enteros o decimales

- boolean → true o false

- null → ausencia de valor

- undefined → variable sin valor asignado

- symbol → identificador único

- bigint → números muy grandes

**No primitivos / Objetos (mutables):**

- Object → Colección de pares clave-valor.

- Array → Lista ordenada de elementos.

- Function → Bloques de código reutilizables.

- Date → Representa fechas y horas.

- RegExp → Expresiones regulares para buscar patrones en texto.

- Map → Colección de pares clave-valor donde las claves pueden ser de cualquier tipo.

- Set → Conjunto de valores únicos.

- WeakMap → Similar a Map, pero las claves deben ser objetos y son “débiles” (permiten recolectar basura).

- WeakSet → Similar a Set, pero solo almacena objetos y son “débiles”.

- Otros objetos construidos por clases → Por ejemplo, instancias de clases personalizadas
