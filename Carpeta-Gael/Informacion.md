## Objetos fundamentales en JavaScript: window y document

- **Objeto window**

  - Representa la ventana del navegador que contiene la página web.
  - Es el objeto global en el entorno del navegador.
  - Proporciona propiedades y métodos para manejar la ventana, como cambiar su tamaño, abrir o cerrar ventanas y manejar el historial.
  - Se utiliza para escuchar eventos que afectan a la ventana, como cambios en su tamaño o cuando se carga completamente.

- **Objeto document**
  - Representa el documento HTML cargado dentro de la ventana del navegador.
  - Es la interfaz para interactuar con el contenido de la página web.
  - Permite manipular elementos HTML, capturar eventos de usuario, crear nuevos elementos o modificar los existentes dentro del DOM (Document Object Model).

### Resumen

- **window** es la ventana o contenedor del navegador.
- **document** es el contenido HTML que se muestra dentro de esa ventana.
- Ambos objetos cumplen roles diferentes pero complementarios para manipular páginas web mediante JavaScript.
